# Onboarding art

Sources for `assets/images/onBordingLight4.png` and `onBordingLight5.png`. They use the same palette as slides 1–3: pink `#FF4D67`/`#FF6584`, navy `#2F2E41`/`#3F3D56`, grey `#F2F2F2`.

Export a source at 1200 px wide to PNG with any SVG renderer (resvg, Inkscape, Figma), then replace the PNG.

For a one-off change without a release, upload the image from the admin panel (System → Onboarding) instead.
